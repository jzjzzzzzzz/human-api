# Privacy disclosure template

Adapt this notice to your jurisdiction and actual retention policy before deployment:

> Answers are written by authorized human responders. Messages submitted to this API may be read by those responders and stored for queue operation, security, and audit. Do not submit passwords, API keys, authentication codes, financial credentials, medical information, or other highly sensitive data. The operator controls retention, access, deletion, and incident response for this deployment.

This repository does not provide legal terms for a specific operator. Deployers must accurately describe their own processing, lawful basis, recipients, retention, user rights, and contact method.
